# Changelog

All notable public changes to OfficePro are recorded here. Versions follow the
release channels described in [RELEASES.md](RELEASES.md).

## [1.0.0] - 2026-11-03

### Added

- First public OfficePro suite release for Windows 10 and Windows 11 (x64).
- Complete suite installer with Start menu entries, optional desktop shortcut and
  uninstaller.
- Portable suite archive (`OfficePro-Suite-Windows-x64.zip`) containing the
  launcher and all four apps.
- Portable launcher (`OfficePro.exe`) with on-demand app downloads.
- In-place suite updates from GitHub releases, preserving installed apps,
  settings, shortcuts and the uninstaller.
- Standalone installers and portable archives for each app.
- SHA-256 checksums for every release asset.
- Per-app licence, notice and attribution files.
