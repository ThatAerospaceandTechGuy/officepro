# Support

OfficePro support is provided through GitHub issues on a best-effort basis. There
is no account system, email support desk or guaranteed response time.

## Before you file

1. Check the [latest release](https://github.com/ThatAerospaceandTechGuy/officepro/releases/latest)
   and read its release notes.
2. Search [existing issues](https://github.com/ThatAerospaceandTechGuy/officepro/issues)
   for the same error or behaviour.
3. Verify the download against `SHA256SUMS.txt` from the same release.
4. Try the current build from a clean folder before reporting an installation
   problem.

## Open an issue

Use the [issue tracker](https://github.com/ThatAerospaceandTechGuy/officepro/issues)
and include:

- the product and version (for example, `OfficePro 1.0.0` or `Word Pro 0.14.0`);
- the exact asset you downloaded (`OfficePro-Setup.exe`, `WordPro-Windows-x64.zip`,
  and so on);
- Windows version and architecture;
- whether you used the suite installer, a standalone installer, the suite archive
  or the portable launcher;
- exact reproduction steps;
- the complete error message or a screenshot;
- whether the SHA-256 hash matched.

Remove personal paths, document contents, email addresses, tokens and other
sensitive information from screenshots and logs before posting.

## Security reports

Do **not** open a public issue with exploit details or a malicious file. Follow
[SECURITY.md](SECURITY.md) and use the repository's private reporting channel.

## What is not supported here

- The application source is private, so this repository does not accept source
  code contributions or build patches.
- Older releases are not patched; update to the current release first.
- Third-party cloud clients (OneDrive, Google Drive) are supported by their own
  vendors.

Product feedback and reproducible bug reports are welcome. Feature requests may
be closed if they are outside the current scope.
