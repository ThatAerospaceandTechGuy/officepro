# OfficePro downloads

Native Windows apps for documents, spreadsheets, presentations and PDFs. Start with the launcher and choose only the apps you need.

**[Download OfficePro →](https://officepro.pages.dev)**

## Releases

Every build is published on the [latest release](https://github.com/ThatAerospaceandTechGuy/officepro/releases/latest):

| Asset | What it is |
| --- | --- |
| `OfficePro.exe` | The launcher. Download this first. |
| `WordPro-Windows-x64.zip` | Word Pro and its licence/notice files |
| `SheetPro-Windows-x64.zip` | Sheet Pro and its licence/notice files |
| `SlidesPro-Windows-x64.zip` | Slides Pro and its licence/notice files |
| `PDFPro-Windows-x64.zip` | PDF Pro and its licence/notice files |
| `OfficePro-Suite-Windows-x64.zip` | Launcher and all four apps in one archive |
| `SHA256SUMS.txt` | SHA-256 checksums for the downloads |

## Install

1. Download `OfficePro.exe` and put it in a folder you control.
2. Run it and press **Get** next to any app you want. The launcher downloads and unpacks the app beside itself.
3. Press **Open** to launch an installed app.

The apps are portable. The suite archive can simply be extracted and run without an installer.

## Notes

- Windows 10 or Windows 11, 64-bit.
- The launcher is unsigned, so Windows SmartScreen may ask you to confirm it.
- No account, telemetry, background service or runtime internet requirement. A connection is needed only when downloading an app.
- Cloud sync is optional and uses the OneDrive or Google Drive desktop client you already have. OfficePro does not create its own cloud folder.
- Licences, third-party notices and attribution files are included in every app folder.

This repository hosts release downloads. The application source is not published here.
